
# SPSS Statistical Analysis Portfolio

[![Hits](https://hits.sh/github.com/Shah-Md-Tasrif-Rahman/Portfolio_SPSS-CUSPC.svg)](https://hits.sh/github.com/Shah-Md-Tasrif-Rahman/Portfolio_SPSS-CUSPC/)

This repository contains a collection of statistical analysis projects completed using IBM SPSS Statistics, which documents my experience with data preparation, statistical analysis, visualization, and communicating results. These projects were completed as a part of an SPSS course hosted by [Programming Club, Dept. of Statistics, CU](https://www.linkedin.com/company/programmingclub-stat-cu/), and conducted by [Md Ahsanul Islam (Himel)](https://www.linkedin.com/in/mdahsanulhimel/).

**The core strength of this portfolio is that I've tried my level best to use syntaxes as often and as robustly as possible, so that my work can be replicated, as reproducibility is an important concern in research. These projects cover a range of common data management, visualization, inferential, and regression techniques used in applied statistical analysis.**

## Datasets

All datasets used in this collection are synthetic data, apart from the final project, which uses a [modified Telco Customer Churn dataset (initially provided by IBM)](https://www.kaggle.com/datasets/jethwaaatmik/telco-customer-churn-dataset/).

All used datasets are provided with the projects for reproducibility.
## Projects

### [Assignment 1](/Assignment-1)
This project uses a dataset which contains survey information about university students, their stress levels, GPA, weekly study time, average sleep time, and a few other concerned variables.

#### Key analyses & methods:
- Basic data importing/loading
- Defining/labelling variables
- Recoding variables
- Reverse coding variables
- Handling missing values
- Identifying and removing duplicate observations
- Descriptive statistics
- Data visualization (Histogram, Bar chart)

### [Assignment 2](/Assignment-2)
This project uses a dataset of a fictional company, which contains sample data of employees, their age, education and experience years, company-funded training time, region, and their gross annual salary.

#### Key analyses & methods:
- Custom tables in SPSS
- Descriptive statistics
- Data visualization (Histogram, Bar chart, Boxplot, Scatter plot)
- Pearson correlation and correlation matrix
- Linear regression
- Regression analysis and testing the statistical significance of slope coefficients

### [Assignment 3](/Assignment-3)
This project uses a dataset of a maternal and child health survey, which contains mother's ID, child's birth weight status (Normal or low weight), mother's age, number of antenatal care (ANC) visits during pregnancy, household wealth index, and place of residence.

#### Key analyses & methods:
- Custom tables in SPSS
- Descriptive statistics
- Hypothesis formulation and testing
- Independent-Samples t-test
- Levene's test
- Binary logistic regression
- Model fit assessment (Hosmer-Lemeshow test)
- APA-style reporting

### [Final Project](/Final%20Project)
This project uses a [modified Telco Customer Churn dataset (initially provided by IBM)](https://www.kaggle.com/datasets/jethwaaatmik/telco-customer-churn-dataset/) to examine patterns associated with whether a customer has left the company (customer churn). The raw CSV file contained 7,043 customer records with 21 variables, including demographic characteristics, service variables, contract and payment information, continuous variables related to charges, and the binary churn outcome.

#### Key analyses & methods:
- Handling missing values
- Custom tables in SPSS
- Descriptive statistics
- Hypothesis formulation and testing
- Normality tests
- Mann-Whitney U test
- Pearson chi-square test of independence
- Binary logistic regression
- Model fit assessment (Hosmer-Lemeshow test)
- Data visualization (Histogram, Bar chart, Boxplot, Stacked bar chart)
- APA-style reporting alongside APA-style tables/graphs

## Repository Structure

Each project is organized into its own directory and contains the relevant files for that analysis:

- `README.md` - Project overview and key findings
- `Final Output/` - SPSS Output/Report
- `Graphs and tables/` - Selected tables and visualizations
- `SPSS Files/` - Contains all the SPSS files (.sav, .sps, .spv)

**Individual project READMEs contain the detailed results, visualizations, and full reports.**
